# Dulce Cafecito — User Flows

## Customer Ordering Flow

Home

→ Menu

→ Select Drink

→ Customize Drink

→ Add to Cart

→ Review Cart

→ Select Pickup Time

→ Select Payment Method

→ Place Order

→ Order Confirmation

→ Track Order

→ Pickup

→ Order Completed

---

## Owner Order Flow

Admin Login

→ Dashboard

→ View New Orders

→ Open Order

→ Confirm Order

→ Preparing

→ Ready for Pickup

→ Completed

---

## Card Payment Flow

Customer Places Order

→ Stripe Checkout

→ Payment Confirmation

→ Order Marked Paid

→ Loyalty Points Awarded

---

## Manual Payment Flow

Customer Places Order

→ Selects Cash App or Zelle

→ Payment Pending

→ Owner Confirms Payment

→ Order Marked Paid

→ Loyalty Points Awarded

---

## Cash Payment Flow

Customer Places Order

→ Select Cash

→ Owner Confirms Order

→ Customer Receives Pickup Information

→ Customer Pays at Pickup

→ Owner Marks Payment Paid

→ Loyalty Points Awarded
